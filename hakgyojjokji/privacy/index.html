개인정보처리방침 정정 및 변경 준비 안내

주식회사 케이티나스미디어는 학교쪽지의 기존 안내 중 실제 처리 구조와 다른 설명을 바로잡습니다. 아래는 확인된 사실의 정정과 앞으로의 변경 준비 안내입니다. 새 개인정보처리방침 전체의 시행 공고나 새 처리에 대한 동의 요청은 아닙니다.

종전 본문의 사실 설명과 이 안내가 다른 부분은 이 정정 내용을 확인해 주십시오. 종전에 약속한 이용자의 권리, 회사의 보호·파기 의무와 더 유리한 조건은 그대로 보존합니다. 이 안내로 과거 처리에 대한 동의를 새로 받았다고 보거나 기존 자료의 처리 조건을 소급하여 바꾸지 않습니다.

1. 지금 바로잡는 처리 내용

가입 여부와 서버 기록

공개 가정통신문 쪽지는 학부모 회원 가입 없이 볼 수 있습니다. 그러나 회원 가입이 없다는 것이 서버 기록도 없다는 뜻은 아닙니다. 앱에는 연결을 신청하기 전에도 기기에서 만든 임의 식별정보와 Firebase 익명 인증정보를 생성하고 서버에서 연결 정보를 조회하는 경로가 있습니다.

교사에게는 이메일·비밀번호로 등록하는 계정이 있습니다. 담임 연결을 이용하면 보호자 표시 이름과 자녀 이름·학교·학년·반, 연결 상태가 서버에서 처리됩니다. 자녀 정보는 신청 확인뿐 아니라 연결된 대화와 상담에서 상대방을 확인하는 데에도 쓰입니다.

학교·학년·언어 선택은 쪽지 요청 때 서버로 전송됩니다. 기기의 쪽지 선택 설정과 서버에 저장하는 담임 연결 정보는 서로 다릅니다. 회사의 기기 내 이용 계측 기록을 분석 서버로 보내지 않는다는 설명은 Firebase·광고·번역 SDK가 별도로 처리하는 정보까지 포함한 설명이 아닙니다.

공유 문서와 AI 처리

공유 문서의 처리 범위는 「텍스트만 전송」이 아닙니다.

  • PDF는 원본 파일과 파일명이 OpenAI 입력에 포함됩니다.
  • 이미지는 원본 이미지 데이터가 입력에 포함됩니다. 통상적인 이미지 처리에서 별도 파일명 항목은 보내지 않지만, 이미지 안의 글자·얼굴 등 개인정보가 제거된다는 뜻은 아닙니다. 회사의 문서 처리 서버는 파일명도 받습니다.
  • HWP·HWPX 등은 추출한 텍스트와 파일명에서 유래한 제목을 처리합니다. 일부 이름·연락처 정제가 모든 개인정보 제거를 보장하지는 않습니다.
  • 교사가 작성한 공개 공지의 제목·본문·기한과 투표의 질문·설명·보기는 비한국어 조회에서 번역이 필요할 때 OpenAI 입력이 되고, 원문과 번역이 학교 단위로 저장될 수 있습니다. 개인별 투표 선택이나 사적인 대화·상담을 이 번역 입력으로 보내는 경로와는 다릅니다.

회사의 공유 문서 처리 경로는 공유 원본·추출문·결과를 장기 보관용 데이터베이스에 저장하지 않고 요청 처리에 사용합니다. 이는 외부 AI 업체의 기록까지 응답 직후 모두 삭제된다는 뜻이 아닙니다. 종전의 OpenAI 「보관하지 않습니다」라는 단정은 바로잡습니다.

OpenAI의 공식 API 안내는 응답 상태의 기본 30일 보관과 해당 저장 경로의 최소 30일 보관 설명, 일반 오용 방지 기록의 최대 30일 보관 및 법적 필요·위해 방지 등에 따른 더 긴 보관 예외를 구분합니다. 상태 저장을 끄는 설정은 모든 보안 기록을 없애는 설정이 아닙니다. API 데이터를 기본적으로 모델 학습에 사용하지 않는다는 안내도 무보관과는 다릅니다. 이번 안내는 회사 계정에 특별한 무보관 조건이 적용됐다는 확인이 아닙니다.

상대방 전달·사진·건강 내용

서버에는 공개 학교자료의 파생물뿐 아니라 계정·기기 식별정보, 연결, 대화, 사진 참조, 상담, 투표 정보도 저장됩니다. Firebase에는 인증정보, 대화 전달을 위한 방 정보와 일부 메시지 사본, 사진이 처리됩니다.

  • 1:1 대화·사진·상담은 연결된 상대방에게 전달됩니다.
  • 교사 공개 공지는 해당 학교·학년을 선택한 이용자에게 표시됩니다. 승인된 1:1 연결의 보호자만 보는 기능이 아닙니다.
  • 투표 목록·집계는 학교 기준 조회로 제공됩니다. 상대방에게 개인별 선택 명단을 제공하는 기능은 아니지만, 회사 서버는 참여자 식별정보에 선택을 연결하여 처리합니다.
  • 자녀 사진이나 건강·알레르기·복약 내용은 선택한 사진·글·상담 사유·공유 문서에 포함될 수 있습니다. 「사진·건강정보는 어떤 경우에도 받지 않는다」 또는 「민감정보가 전달될 가능성이 없다」고 설명할 수 없습니다.
  • 교사 계정의 연락처를 보호자에게 표시하는 항목이 없다는 것과 작성자가 본문에 적은 연락처까지 모두 제거된다는 것은 다릅니다.

사진·건강 관련 소통을 일괄 금지하는 것은 아닙니다. 필요한 아동의 법정대리인 동의·확인, 민감정보의 별도 동의 및 상대방 제공의 적법한 근거는 따로 갖추어야 합니다. 초대 코드 소지, 교사의 수락, 로그인 또는 이 안내 열람만으로 필요한 절차를 모두 마쳤다고 보지 않습니다. 불필요한 개인정보를 공개 공지·투표에 적지 않고, 전송할 문서·사진의 포함 내용을 확인해 주십시오.

국내 저장과 국외 처리

확인된 Firestore 대화 저장소와 사진 저장소의 저장 리전은 대한민국 서울입니다. 그러나 Firebase Authentication은 공식 안내상 미국에서 인증 데이터를 처리합니다. Supabase의 데이터베이스 저장 위치와 서버 실행·지원·로그 처리 위치도 구분해야 합니다. 국내 저장 리전만으로 담임 연결·채팅 관련 정보가 모두 국내에서만 처리된다고 한 종전 설명은 정확하지 않습니다.

종전의 OpenAI·광고 관련 미국 이전 안내 역시 모든 공급자의 모든 처리·지원 위치가 미국 한 곳으로 한정된다는 보증은 아닙니다. 업체별 실제 계약·처리 국가·보관 조건을 확정한 전체 개정 방침은 별도로 안내합니다. 이번 정정은 새로운 국가로의 이전을 승인받았다는 뜻이 아닙니다.

외부 SDK

Google AdMob은 광고 식별정보, IP 주소, 기기·앱 정보, 광고 상호작용·진단 정보를 처리할 수 있습니다. 비맞춤형 광고나 광고 ID 제한이 모든 정보 수집을 중단하는 것은 아닙니다. 동의 결과와 플랫폼 정책에 따라 비맞춤형·제한적 광고 또는 광고 미표시가 적용될 수 있으므로, 거부하면 항상 비맞춤형 광고가 나온다고 단정하지 않습니다.

Google ML Kit가 포함된 배포판에서는 모델 다운로드와 기기·앱·설치 식별정보, 기능·모델 정보, 사용·성능·오류와 언어 관련 기술정보의 통신이 있을 수 있습니다. 온디바이스 번역의 입력·결과는 기기에서 처리되지만, 이것이 앱 전체의 외부 통신이 없다는 뜻은 아닙니다. 번역 끄기도 SDK의 모든 통신이나 기존 기록 삭제와 같지 않습니다.

2. 삭제와 기존 보유 약속

로그아웃, 앱 삭제, 담임 연결 해제, 계정 삭제는 서로 다릅니다. 앱을 지우기만 해서는 서버 계정·연결·인증정보가 자동으로 모두 삭제되지 않습니다. 연결 해제는 해당 연결 자료의 정리와 관계없는 계정·다른 연결·학교 투표 기록의 삭제를 구분해야 합니다. 화면에서 사라졌거나 삭제 요청이 접수됐다는 것만으로 모든 저장소의 파기가 완료된 것은 아닙니다.

사진 저장소에는 현재 확인된 설정상 삭제 뒤 7일간 복구할 수 있는 보존이 있습니다. 30일 뒤 활성 사진을 삭제하는 것과 업로드부터 30일 안에 복구본까지 영구 파기하는 것은 다릅니다. 7일 복구보존을 해제한 상태가 아니며, 이를 이유로 회사의 기존 삭제 의무나 기한을 연장하지 않습니다.

Firebase Authentication의 공개 안내는 IP 로그를 몇 주간, 다른 인증정보를 운영자가 삭제를 시작할 때까지 처리하고, 삭제 개시 후 운영·백업 시스템에서 180일 이내 제거한다고 설명합니다. 이는 회사가 이용자 자료 전부를 180일간 보관한다는 뜻도, 모든 자료를 즉시 삭제했다는 뜻도 아닙니다. 상대방이 별도로 저장한 사진·화면 캡처, 외부 캘린더 일정, 기기·외부 서비스의 백업도 회사 원본의 삭제와 구분됩니다.

종전의 연결 해제 시 지체 없는 파기, 상담 신청일부터 1년 또는 연결 해제, 투표 종료 후 6개월, 교사 탈퇴 또는 최종 로그인 후 1년, 문의 처리 완료 후 30일 등 기존에 적용되는 보유·파기 약속을 이번 안내로 늘리거나 없애지 않습니다. 실제 삭제가 끝나지 않은 항목을 완료로 안내하지 않아야 하며, 이 설명이 지연이나 누락을 면책하지 않습니다.

기존 약관의 교사 계정·초대 코드 삭제를 접수일부터 10일 이내에 처리하고 결과를 알리는 약속, 정보 삭제 요청에 대한 10일 이내 결과·사유 안내도 유지합니다. 공급자 보존 조건을 설명했다고 이 약속이 자동으로 바뀌는 것은 아닙니다.

3. 부모 로그인·Apple 로그인과 30일 기준 — 아직 시행 전

회사는 부모 계정 로그인과 Apple 로그인 선택지를 추가하는 작업을 준비하고 있습니다. 공개 쪽지의 비회원 열람은 유지하는 방향입니다. 이번 게시로 부모 로그인·Apple 로그인을 사용할 수 있게 되거나 기존 기기 기록이 자동으로 계정에 합쳐지는 것은 아닙니다. 실제로 받는 로그인 정보, 업체의 역할·처리 조건, 계정 삭제·Apple 연결 철회 방법을 기능 제공 전에 안내합니다. 로그인 자체는 자녀·건강정보·AI·광고 등에 필요한 별도 동의를 대신하지 않습니다.

채택한 정상 보유 기준은 다음과 같습니다. 운영 적용 전의 준비 기준이며, 이 안내만으로 자동 파기가 시작됐다고 보지 않습니다.

  • 1:1 채팅 메시지: 작성 시점부터 30일. 예약 전달 대기 기간도 포함합니다.
  • 사진: 서버 업로드 시점부터 30일. 메시지로 보내지 않은 업로드도 포함하며, 나중에 전송해도 기간을 다시 시작하지 않습니다.

  • 투표 질문·보기·번역과 교사 공개 공지에는 개인별 응답의 30일 기준을 일괄 적용하지 않습니다.

(2) 계정 삭제 및 관련 데이터 삭제

  • 수집 항목: 자녀의 이름, 학년, 반
  • 수집 목적: 담임 선생님이 연결 요청을 확인하고 수락하기 위해서. 그 밖의 목적으로 쓰지 않습니다.
  • 보유 기간: 연결이 살아 있는 동안. 연결을 끊거나 앱을 삭제하면 지체 없이 파기합니다.

학부모·보호자는 동의를 거부할 수 있으며, 그 경우 담임 연결 기능만 쓸 수 없고 가정통신문 쪽지·번역·일정 기능은 그대로 이용할 수 있습니다.
