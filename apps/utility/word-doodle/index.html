SERVICE서비스 설명

단어 하나, 나만의 그림 하나.

그려보카는 영단어를 낙서로 기억하는 학습 앱입니다. 잘 그릴 필요는 없어요. 단어를 보고 떠오른 그림이 나만의 기억 단서가 됩니다.

만 14세 이상을 위한 영단어 학습

읽고, 그리고, 다시 떠올려요.

01단어를 읽고

영단어와 뜻을 확인하며 머릿속에 떠오르는 장면을 생각해요.

02낙서로 남기고

직접 그린 그림으로 단어를 표현해요. 나에게 의미 있는 낙서면 충분해요.

03내 그림으로 복습

기기에 저장한 그림과 학습기록을 바탕으로 단어를 다시 떠올려요.

가입 없이 시작하는 나만의 단어 노트

그려보카는 회원가입이나 로그인 없이 이용합니다. 낙서와 학습기록은 기기에 저장되며, 회사 서버로 전송하거나 동기화하지 않습니다. 복습 일정도 기기 안에서 계산합니다.
